# aboutdbanks.com

Personal portfolio website showcasing my work as an IT Infrastructure Engineer and music producer.

🌐 **Live Site**: [aboutdbanks.com](https://aboutdbanks.com)

## Overview

This is my personal portfolio website built with vanilla HTML, CSS, and JavaScript. It features a modern, responsive design with dark mode support, smooth animations, and showcases both my technical projects and music production work.

## Features

- ✨ **Modern Design** - Clean, professional layout with smooth animations
- 🌙 **Dark Mode** - Toggle between light and dark themes with persistent preference
- 📱 **Fully Responsive** - Optimized for all devices and screen sizes
- 🎨 **Smooth Animations** - Fade-in effects, parallax scrolling, and hover animations
- ⚡ **Fast Loading** - Vanilla JS with no heavy frameworks
- 🎵 **Music Section** - Showcases my beat tapes with streaming links

## Sections

1. **Hero** - Introduction with profile picture
2. **About** - Professional background and expertise
3. **Skills** - Technical skills organized by category
4. **Projects** - Featured technical projects and implementations
5. **Music** - Beat tape showcase with streaming platforms
6. **Contact** - Professional contact information

## Technologies Used

- HTML5
- CSS3 (with CSS Variables for theming)
- Vanilla JavaScript
- Google Fonts (Inter)
- GitHub Pages for hosting

## Local Development

1. Clone the repository:
```bash
git clone https://github.com/dbankscard/aboutdbanks.com.git
cd aboutdbanks.com
```

2. Open `index.html` in your browser or use a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx http-server
```

3. Visit `http://localhost:8000` in your browser

## Customization

- **Colors**: Edit CSS variables in `:root` section of `styles-enhanced.css`
- **Content**: Update text content in `index.html`
- **Images**: Replace `profile.jpg` and `beat-tape-cover.jpeg` with your own
- **Projects**: Add or modify project cards in the projects section

## Deployment

This site is automatically deployed to GitHub Pages when changes are pushed to the `main` branch.

### Custom Domain Setup
1. Add your domain in GitHub Pages settings
2. Configure DNS records:
   - A records pointing to GitHub Pages IPs
   - CNAME record for www subdomain
