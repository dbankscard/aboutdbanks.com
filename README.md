# aboutdbanks.com

Personal site for Dwight Banks, senior systems and platform engineer.

Live at [aboutdbanks.com](https://aboutdbanks.com), served by GitHub Pages from the `main` branch.

## Files

- `index.html`, `styles.css` – the site. Plain HTML and CSS, no build step, no JavaScript.
- `resume/index.html` – web version of the resume.
- `Dwight_Banks_Resume.pdf` – downloadable resume.
- `profile.jpg`, `favicon.svg` – assets.

## Updating the resume

The resume content lives in a small data file that generates the Word document, the web page, and the PDF so they never drift. Regenerate all three, then copy the outputs here.
